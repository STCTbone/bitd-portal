# Blades ’68 reference pointers

This repository implements fresh Blades ’68 campaigns. Use [the glossary](GLOSSARY.md) and [architectural decisions](docs/adr/) before changing domain behavior. [The development guide](app/README.md) describes the active runtime; [feature contracts](docs/backend-contracts.md) record authorization and concurrency boundaries.

For rules changes, verify the relevant published Blades ’68 v6 playbook/crew sheets and the supplied v1.0.1 book; record source/version and any discrepancy. The full book and source artwork remain outside Git. This checkout contains no reference PDF collection. Existing UI guidance and [the adaptation design](docs/design/blades68-adaptation.md) identify verified content, explicit manual procedures and house-rule labels.

Original-game coin/stash, trauma, downtime, automatic advancement and older playbook/crew catalogs are historical upstream concepts, not this portal's baseline. Source names in historical research refer to its recorded upstream revision; inspect current migrations and active feature modules for present contracts.
