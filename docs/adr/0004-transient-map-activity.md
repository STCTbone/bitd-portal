# Recheck access on every transient map exchange

Map cursors, pings and drawing gestures use authenticated Supabase RPC sends and 250 ms polling reads, each checking current campaign membership and the currently selected usable shared map. Supabase remains the backend; an unlogged, bounded, expiring geometry table supplies this transient channel without granting websocket or durable-token access, because [Realtime authorization caches permissions for a connection](https://supabase.com/docs/guides/realtime/authorization#updating-rls-policies) rather than checking every message. This trades modest polling load and latency for straightforward current receive isolation; gestures disappear after seconds, local access leases reject late responses, and database restarts may erase all transient activity.
